On his account the app shows admin things a member never sees: the Donation tile opens the campaign list instead of the donation page (`quick-grid.component.ts` 98-101), Streaming shows Edit and Delete on every card plus empty cards (`liveStraming.component.html` 24-33), and event details show Edit and Delete (`eventDetails.component.html` 9). Raised by: director, PM, PO. Options: (a, recommended) add a member persona to `engine/demo/world.mjs` (home Maple Grove Masjid, follows Cedar Hill Masjid, no organisation role, profile complete, not a volunteer), plus a second member whose masjid has no donation page for 15.4 [2.4]; (b) record Track 15 on dev with a member test account; (c) use Yusuf and crop the admin controls (not possible for the Donation tile).
2. **Native phone screens in Track 15.** The mocked world runs the web app only. These shots are phone screens: the Qiblah compass and the denied-location take (15.1 [5.2a], [6.1]-[6.2]), the maps hand-off (15.2 [5.1]), the share sheet (15.3 [4.2], 15.8 [7.2]), the gallery and form downloads (15.6 [4.3], [5.3], which use `window.open` and may not open in the app at all, as flagged), and the recitation audio. The decision on native pages covers only 00.7's phone screens. Raised by: director, PM. Options: (a, recommended) capture these few shots on the emulator from the app build, with the same demo data, and cut them in; check the 15.6 downloads on that build first and cut [4.3] and [5.3] if they fail; (b) stylised graphics for the share sheet and maps, emulator only for the compass; (c) cut the native shots.
3. **Which Quran build to record?** You said the app now self-hosts the Quran data. In the code it's on `feat/quran-self-hosted` (152336b4d "serve the reader's text, Mushaf pages and fonts from our own storage", ce6be1ea1 "leave offline reading out of this release"), not on `origin/master` 7f0e6bf72, which still reads api.alquran.cloud (`quran.service.ts` 15). The reader's labels are the same on both, so the scripts don't change. The demo world must serve whichever source the recorded build reads. Raised by: PM, PO. Options: (a, recommended) record 15.5 and 15.8 from a build with the self-hosted copy once it's merged, and have the demo world answer `GET /public/Quran/Source` and the copy's files; (b) record from master now, with the demo world answering the AlQuran Cloud calls.

Many events have none, and then the message has only the title, with no way to open the event. 15.3 now says "send the event", and its demo event has a link. Raised by: PO, user.
