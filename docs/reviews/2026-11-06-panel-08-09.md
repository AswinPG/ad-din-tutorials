## Needs your decision

1. **08.5: PayPal gifts on a masjid campaign can't appear today.** The video shows PayPal rows in a masjid campaign's list. These rows come from a daily import that uses the organisation's PayPal keys, and a masjid can't save its keys (Integrations tab bug, `editMasjid.component.html` passes the madrasah id). So a masjid admin will never see the rows the video shows. The decision "Record without PayPal" removed the PayPal step from 08.3, but 08.4 and 08.5 still show PayPal working. Raised by: PO, user, PM. Evidence: docs/APP-ISSUES.md, first row; 08.5 flags. Options: (a, recommended) fix the one-line binding (`[orgId]="masjidId"`) before 08.4 and 08.5 are published, then put the PayPal step back in 08.3; (b) record 08.4 and 08.5 on Maple Grove Madrasah, where the keys save; (c) publish as is.
2. **08.1: the event form doesn't check Premium until you save.** The web route's Premium guard is commented out (`events.routes.ts` 11), but the server refuses to save an event from an admin without Premium (`EventsController.cs` 57-58). An admin without Premium fills in the whole form and then gets an error. The campaign form checks first (`donations.routes.ts` 12). Raised by: PO, user. Options: (a, recommended) put the guard back, so the Premium page opens before the form, and log it in APP-ISSUES; (b) leave it. Either way, [1.2] now says Premium is needed.
3. **Madrasah admin playlist: no event or website videos.** 08.1 shows madrasah events ([2.2], [6.2]). 09.1 to 09.5 cover the **Madrasah Website**, its analytics and the link request, which 09.4 sends from the madrasah. The Madrasah admin playlist has none of them. Raised by: PM. Options: (a, recommended) add `"08.1"` and `09.1-09.5` to `playlists → Madrasah admin` and rebuild the plan; (b) leave it as planned.
4. **09.1 [4.3]: what happens to the old address?** If an admin changes the website address after sharing it, it isn't known whether the old address still works. A volunteer will worry about this. Raised by: user, PO. Options: (a, recommended) confirm with the team, then add one line, for example "Choose your address before you share it: the old one stops working"; (b) say nothing.
