Ad-Din Tutorial Series

A complete video series for Ad-Din, from creating an account to using every feature. Every video is self-contained and under five minutes. The order follows a new customer: create an account, register the organisation, subscribe, set it up, then use it day to day.

Rules every video follows

  • Self-contained. Each opens with a “You’ll need” card: role, plan, and what must already be set up. Prerequisites are listed so viewers can jump back, but the video works on its own.
  • Five minutes or less. Target 3–5 minutes. Longer topics split into Part 1 / Part 2, each standing alone.
  • One job per video. The title is the task (“Create class sections”), not the screen name.
  • One demo world. One seeded masjid and madrasah with fixed demo users, so screens match across all videos and can be re-recorded.
  • Real labels. Every on-screen word in a script is taken from the app’s own text.
  • Same shape. What you’ll be able to do (10 s) → You’ll need (5 s) → numbered steps → recap → related videos.
